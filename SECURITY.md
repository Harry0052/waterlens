# Security

WaterLens is a local scoring tool. It does not run a service, store accounts, or connect to meters.

Report a vulnerability through GitHub private vulnerability reporting:

https://github.com/Harry0052/waterlens/security/advisories/new

Please do not open a public issue that includes exploit details.

What helps a report:

- The WaterLens version or git commit.
- The command you ran and the fixture shape, with any real household data removed.
- The impact you observed.

This repository does not ship credentials. Please do not send secrets in the report.
